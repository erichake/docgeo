Formulas and programs

The language of expressions is that of DGPad. DocGeo interprets it itself: it is never run as JavaScript.

Values

Writing Value
3, -2.5, .5, 2e3 numbers (decimal point)
PI, π π (pi is not recognized)
1 + 2i complex number
30° angle in degrees, converted to the figure’s angle unit
"text" text; + concatenates
[1, 2, 3] list; [x, y], [x, y, z]: point or vector
A point: coordinates; segment: length; circle: radius; polygon: area; angle: measure
x, y, z, t variables of a function

In the plane, a point is a complex number: (A + B)/2 is the midpoint, 2*B - A the reflection of A in B.

Operators

+ - * / ^ % operations, power, remainder
2x, 2π, 3(x + 1) implicit multiplication
== != < <= > >= comparisons, worth 1 or 0; == tolerates rounding errors
&& || ! and, or, not
test ? a : b condition
L[0], A[1] element, coordinate (from 0)
L.length length of a list

Functions

Function Value
d(A, B), distance(A, B) distance (in space in 3D)
x(A), y(A) coordinates
Angle360(A, O, B), Angle180(A, O, B) directed angle from [OA) to [OB); geometric angle AOB
rotate(P, O, a), dilate(P, O, k) image of P by the rotation of center O and angle a; by the dilation of center O and ratio k
sqrt, abs, exp, log square root, absolute value, exponential, natural logarithm
sin, cos, tan, asin, acos, atan, atan2(y, x) in degrees or radians according to the figure’s Angles setting (degrees by default)
floor, ceil, round rounding
min(…), max(…), gcd(a, b), isNaN(a) minimum, maximum, GCD, test for an undefined value
arg, mod, conj argument, modulus, conjugate
dot(u, v), cross(u, v), unitVector(u), perp(u) dot and cross products, unit vector, orthogonal unit vector
pixel(), windoww(), windowh(), windowcx(), windowcy() pixels per unit; size and center of the window in units
theta(), phi() angles of the 3D camera
f(2), f'(2), f''(2) call of an expression that is a function of x, of its derivative, of its second derivative

Programs

Statements separated by ; or line breaks; the last one gives the value.

variables var s = 0 (let, const); s += 2, -=, *=, /=, L[2] = 5
conditions if (a > 0) { … } else { … }
loops for (var k = 0; k < 10; k++) { … }, while (…) { … }
functions function square(u) { return u*u }
lists L.push(P), L.pop(), L.concat(M), L.join(", ")

The variables of a program hide the objects with the same name. An endless loop is interrupted.

Object methods

S.setHidden(1), S.setShowName(1) hide, show the name (0: the reverse)
S.setRGBColor(r, g, b), S.setOpacity(o), S.setSize(t) color (0 to 255), opacity (0 to 1), size or thickness
a.setPrecision(n), a.setIncrement(p) decimal places, step of a slider
P.getX(), P.getY(), P.coords3D(), P.coords2D() coordinates; coordinates on the screen
S.getName(), c.center() name, center of a circle
