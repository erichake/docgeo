Formulas and programs

The language of expressions is that of DGPad. DocGeo interprets it itself: it is never run as JavaScript.

Values

PI, π π (pi is not recognized)

30° angle in degrees, converted to the figure’s angle unit

In the plane, a point is a complex number: (A + B)/2 is the midpoint, 2*B - A the reflection of A in B.

Reading another tab

In a workbook, a formula reads the value of an object of another tab, as in a spreadsheet: the tab name in single quotes, an exclamation mark, the object name. 

m = 'Figure 1'!c
area = Data!p * 2
  • The quotes are not needed if the tab name has no space or sign (Data!p); an apostrophe in the name is written \' ('Tom\'s'!c).
  • The value is the one a formula of that tab would read: coordinates of a point, length of a segment… A function cannot be read.
  • Read only: nothing in a tab changes another tab. The value is read again when you come back to the tab that reads it. Only exception: program globals, common to the whole workbook.
  • A tab cannot read itself, nor a tab that reads it (“Circular reference”). An unknown tab or object is refused when typed.
  • Renaming a tab, or an object of the tab shown, updates the formulas of the other tabs. After a tab is deleted, the formulas that read it are undefined.

Reading a spreadsheet cell

In a tab that has a spreadsheet view, a formula reads its cells through the sheet’s name: a cell, a range (a list), or a cell of another tab. 

r = Sheet1!B3
L = Sheet1!B2:B21
k = 'Spreadsheet 1'!Sheet1!A1

An empty cell or a cell in error gives an undefined value. The other way round, a cell reads an object of the figure with =GEO("name") (GEO).

Programs

Statements separated by ; or line breaks; the last one gives the value.

variables var s = 0 (let, const); s += 2, -=, *=, /=, L[2] = 5
conditions if (a > 0) { … } else { … }
loops for (var k = 0; k < 10; k++) { … }, while (…) { … }, break, continue
functions function square(u) { return u*u }
lists L.push(P), L.pop(), L.concat(M), L.join(", ")
globals GLOBAL_SET("n", 5), GLOBAL_INC("n", 1), GLOBAL_GET("n")
pause WAIT(500): 500 ms, in a button’s program

The variables of a program hide the objects with the same name. An endless loop is interrupted. Globals are shared by all the programs of the figure, its buttons included.

A program is a parent of the objects it styles: it is recomputed with the figure, and a redefinition that would create a cycle is refused.
