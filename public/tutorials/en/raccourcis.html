Shortcuts and gestures

Keyboard

Ctrl S save
Ctrl Shift S save as
Ctrl O open
Ctrl Z; Ctrl Shift Z, Ctrl Y undo; redo
Delete, ⌫ delete the object or the selection
Esc drop the tool, close the ring, clear the selection, leave eraser, magnets or step by step, then close the properties or the tool palette
P, S (3D) perspective, floor
← → Home End steps of step by step

Text lines

Enter confirm; insert the highlighted completion
Esc close the completion, otherwise restore the line
↑ ↓, Tab browse, insert the completion
click on an object write its name

Programs (Definition)

Ctrl Enter apply, create
Enter, Tab, } indented line, indent, unindent
Esc restore the applied text
Ctrl C, Ctrl X, Ctrl V in the blocks: copy the block and those under it, cut the block alone, paste

Mouse and finger

touch an empty spot / a crossing / an object, palette closed free point / intersection / selection and ring
Ctrl-click, Shift-click, long press multiple selection
Shift-click during a tool keep the argument until you leave the tool
drag an empty spot; right button move the view; in 3D, the right button rotates
one finger on an empty spot move the view; rotate in 3D
wheel, trackpad zoom
two-finger pinch zoom around the midpoint between the fingers
drag a name, an angle mark, an expression place it; change the arc radius
touch a name rename
finger pressed during a tool aim, designate on release
drag on a number field adjust (Shift: finely)
edge of a panel resize; double-click: default width
tab of a page double-click: rename; right click: page menu; drag: move (workbooks)
