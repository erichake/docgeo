Building with the keyboard

One line per object: name = Command(arguments), typed in the input line of the “Construction” panel and confirmed with Enter. 

A = (-5, -2)
B = (4, -3)
C = (-1, 4)
p = Polygon(A, B, C)
c = Circumcircle(A, B, C)
M = Midpoint(A, B)

Syntax

Element Rule
Free point A = (2, 3); A = (2, 3, 1) in 3D
Polar coordinates P = (3; 60°): radius and angle separated by a semicolon
Free vector u = (2, 1): lowercase name; drawn from the origin, it is dragged by its tip
Numbers decimal separator: the point (2.5); (1,5, 2) is a point with three coordinates
Command case and accents ignored (perpendicularbisector(A, B)), the English name is accepted in every language; the line is rewritten in the usual form
Number argument number, name of an expression or a slider, or formula: Circle(A, 2*r)
Name left out Midpoint(A, B): automatic name, uppercase for a point, u, v, w for a vector, a Greek letter for an angle, lowercase otherwise (not e, i, k, l, o, t, x, y, z)
Unknown name starting with a lowercase letter, it becomes a slider: A = (a, 4), d = y = m x + p
Existing name the line redefines the object
Special name apostrophe allowed (A'); other characters between backquotes (`aux 2`)
Names to avoid x, y (equations), i (imaginary unit)
Other line neither point nor command: an expression (a = 3, E = d(A, B))

Forms and arguments of each command: Commands.

Completion and designation

  • The list offers the commands at the start of a line, then, between parentheses, only the objects the current argument accepts, highlighted in the figure. ↑ ↓ choose, Tab or Enter insert, Esc closes.
  • A click on an object writes its name, followed by , or ) depending on what remains to designate: M = Midpoint(, click on A, click on B gives M = Midpoint(A, B).
  • In the input line, a click where there is no point creates one (free, on object or intersection); a preview follows the pointer. Clicking the first vertex of a polygon again ends it.
  • Same gesture in a formula: E = d(, click on H then M.

Editing a line

Each line of the panel is a field: Enter confirms, Esc restores.

  • New coordinates: the free point is moved.
  • New definition: the object is redefined, keeps its style, and its dependents follow (M = Midpoint(A, B) → M = (5, 5) → M = Midpoint(B, C)). The construction is reordered if needed; a cycle is refused.
  • New name: the object is renamed in every line and formula.
  • A = deletes A and its dependents.
  • Long command: opens it in the Definition section of the properties, on several lines, with the same completion; clicking an object of the figure inserts its name, ⌘-Enter applies.

Equations

Two sides in x, y (and z) separated by =; the kind of object is read from the coefficients, which may depend on sliders.

Line Object
d = y = a*x + b, x = 3 line
c = x^2 + y^2 = 4 circle
e = x^2/9 + y^2/4 = 1 conic
p = x + y + z = 3 plane (3D)

Degree higher than 2 or not polynomial: refused. At the start of a line, z is a name: z = 3 is an expression, the plane is written p = z = 3.

Intersections and points on objects

  • Intersection(d1, d2) for two lines; Intersection(c, d, n), n from 1 to 4, otherwise.
  • OtherIntersection(c, d, P): the common point farthest from P.
  • Point(c, t), or Point(p, a, b) on a polygon or a conic: position on the object, written by the gesture.

Errors

A faulty line is not applied: it stays framed in red, the prompt gives the reason, the rest of the figure is untouched.

Message Cause
Can’t read parenthesis, comma or character
Unknown command, Unknown object name misspelled or missing
Wrong arguments for … no form matches; “With these arguments” recalls the forms
The name … is taken renaming
An object can’t depend on itself cycle
A plane figure keeps its objects in the plane z = 0… object in space: switch to 3D view
This object has no text form yet imported object without a command: read-only line name = …
