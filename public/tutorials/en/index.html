DocGeo user manual

DocGeo is 2D and 3D dynamic geometry software, compatible with GeoGebra and DGPad file formats.

Open DocGeo

Video presentation

Four ways to build

Method Principle
By gesture Touching an object opens the ring of its tools, as in DGPad.
From the palette Choose the tool, then designate its objects, as in GeoGebra.
By multiple selection Select the objects, then choose the tool in the palette.
With the keyboard Type M = Midpoint(A, B).

All four write the same line in the “Construction” panel, where it can then be edited.

Conventions

  • Buttons are shown by their icon ( eraser), tools by theirs, on the color of their family ( midpoint).
  • Ctrl means ⌘ on a Mac.
  • Search the manual: / or Ctrl K.
