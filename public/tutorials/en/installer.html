Installing DocGeo

In Chrome and Edge, on macOS, Windows or Linux, the DocGeo editor installs on the computer as an application. It needs neither administrator rights nor any software to download.

Installing

  1. Open the editor in Chrome or Edge.
  2. Choose File › Install DocGeo on this computer…
  3. Confirm with Install: DocGeo opens right away in its own window.

This item only appears when the browser offers the installation: not in DocGeo once installed, nor in Firefox or Safari. The browser also offers it through an icon at the right of the address bar.

What you get

  • DocGeo has its own window, without address bar or tabs, and starts from the Dock, the Start menu or the applications menu, like any software.
  • It works without an Internet connection (Offline).
  • Double-clicking a .dgo, .dgp or .ggb figure opens it in DocGeo (Opening a figure by double-clicking).
  • Ctrl N creates a new figure and Ctrl T a new tab, shortcuts that the browser keeps for itself when DocGeo is not installed.

Offline

Once opened online a first time, DocGeo opens and works without a connection: building, opening and saving files on the computer. Only figures opened from a link (Sharing a figure by link) and this manual need a connection.

Opening a figure by double-clicking

Once installed, DocGeo opens .dgo, .dgp and .ggb files: double-clicking one shows it in a DocGeo window. A .dgo figure opened this way is saved back to its file.

If other software already opens these files (DGPad, GeoGebra…), choose DocGeo once and for all: on a Mac, in the Finder, Get Info › Open with, DocGeo, then Change All; on Windows, right-click the file, Open with.

Figure icons on a Mac

On a Mac, a figure’s icon is the DocGeo icon on a page, with the extension in grey. To give each format its own icon, open Terminal (⌘ Space, then type Terminal), paste this line and press Return.

The command then restarts the Finder to show the new icons: its open windows close. 

curl -fsSL https://doctools.org/apps/docgeo/macos-icons.sh | sh

These icons stay after browser updates. The command creates a small app, DocGeo Types, which only declares the icons and never opens. A format opened by other software (DGPad…) keeps that software’s icon.

To go back to the original icons, paste this line:

curl -fsSL https://doctools.org/apps/docgeo/macos-icons.sh | sh -s uninstall

Figure icons on Windows

On Windows, a figure opened by DocGeo has a blank icon. To give each format its own icon, open PowerShell (Start menu, then type PowerShell), paste this line and press Enter. The command asks for nothing and does not restart the computer. 

irm https://doctools.org/apps/docgeo/windows-icons.ps1 | iex

Run it after installing DocGeo, and again if the icons disappear after a browser update. If a format does not open with DocGeo yet (DGPad…), it says so: choose DocGeo for that format (Opening a figure by double-clicking).

To go back to the original icons, paste this line:

& ([scriptblock]::Create((irm https://doctools.org/apps/docgeo/windows-icons.ps1))) uninstall

Figure icons on Linux

On Linux, a figure opened by DocGeo has a generic icon. To give each format its own icon, open a terminal, paste this line and press Enter. The command asks for nothing and does not restart the computer. 

curl -fsSL https://doctools.org/apps/docgeo/linux-icons.sh | sh

Run it after installing DocGeo from Chrome. Close and reopen the file manager to see the icons.

To go back to the original icons, paste this line:

curl -fsSL https://doctools.org/apps/docgeo/linux-icons.sh | sh -s uninstall

Updates

DocGeo updates itself. A new version is downloaded when DocGeo opens, and is used from the next launch, once all its windows are closed. Offline, DocGeo keeps the version it has.

Uninstalling

In the DocGeo window, open the browser’s ⋮ menu, then Uninstall DocGeo. On Windows, DocGeo can also be uninstalled from Settings › Apps. Your figures are not affected.

In Firefox and Safari

Firefox does not install DocGeo: it is used in a tab. Safari on a Mac can put it in the Dock (File › Add to Dock), in its own window, but without opening figures by double-clicking.
