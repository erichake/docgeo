Building by multiple selection

Objects first, tool second: the selected objects become the arguments of the tool chosen in the palette.

Steps

  1. Select the objects: Ctrl-click, Shift-click or long press (0.7 s). Each one glows blue with its rank. If an object’s ring is open, that object becomes the first of the selection.
  2. Open the palette : the tools that do not accept the selection are grayed out. Hovering over a tool shows in the prompt the line it will write. If the selection is enough for it, the object appears pale.
  3. Choose the tool: each object, in the order of the selection, takes the first free place of its type.

Complete or incomplete selection

  • Complete selection: the line is written at once.
  • Incomplete selection: the tool waits for the missing arguments, then designated in the figure.
  • A number (radius, angle, ratio, number of sides) cannot be selected: the tool takes a default value, which you then change in its line.
  • The tool then stays active, as when chosen from the palette without a selection.

Special cases

Tool Selection Result
Polygon three vertices or more polygon closed at once; with fewer, the tool waits for the next vertices
Intersection two objects the intersection point nearest to where the second one was selected
Point one object point on this object, where it was selected
Locus one point its locus; the point on object it depends on is found automatically

Examples

Selection Tool Line written
A, B, C Circumcircle Circumcircle(A, B, C)
D, E, F, images of A, B, C Polygon Polygon(D, E, F)
O, P Rotation Rotation(O, P, 90)
