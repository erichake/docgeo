DGPad and GeoGebra import

.dgo is the DocGeo format; .dgp and .ggb are imported, then saved as .dgo. No export to DGPad or GeoGebra.

The .dgo format

Compressed JSON: objects, styles and view. It only evolves by additions: a saved file remains readable by later versions.

DGPad

Plane and 3D figures, styles, expressions, sliders, animations, loci, magnets, traces and macros are carried over.

DGPad program DocGeo
expression scripts, Blockly that computes an expression, Blockly turtle interpreted
Blockly buttons (styling, changing a number) interpreted
Blockly events: dragging, pressing, releasing a point, change of a value interpreted
other Blockly events, JavaScript, active HTML ignored and reported
“restrictions” expression (locking of the interface) ignored
3D rotation restrictions applied

No code of a figure is run by the browser. Deliberate difference: a curve is not joined by a vertical line at its discontinuities.

GeoGebra

Each command becomes the matching DocGeo object, with the same arguments; points on objects and intersections are put back at the positions saved by GeoGebra.

  • Carried over: plane and 3D geometry, functions and curves (numerical derivatives and integrals), sliders, checkboxes, input boxes, display conditions, LaTeX texts, images, styles and position of names, axes and grid, animations, traces, macros.
  • Not carried over: scripts (GGBScript, JavaScript), computer algebra, some list commands.

More than half of the 470 figures of a corpus from geogebra.org open without loss. An unsupported element is ignored along with its dependents and reported.
