Managing objects

Selection and context area

Touching an object selects it; the context area, in the middle of the bar, shows its name and its actions. Hovering an action shows its effect in the prompt. Esc or a touch on an empty spot deselects.

Action Objects
Delete, with the dependents all
Settings: properties panel all
Animate with the spring point on object, slider
Pin to the screen free point, plane figure
Magnets free point
Point, List of points, List of segments expression whose value is a point or a list

Multiple selection

Ctrl-click, Shift-click or long press (0.7 s) add or remove an object; each one glows blue with its rank. The bar then offers Delete and Settings (shared settings), and the palette takes the selection as arguments. A simple touch, Esc, a tool, the eraser, undo or redo clear it.

Deleting

, Delete or ⌫, or the line A =. The dependents are deleted too: to keep them, hide the object instead.

Hiding and showing

  • The dot of a line of the “Construction” panel is filled if the object is visible, empty if it is hidden; touching it toggles. A point’s dot, with its shape and colors, fades instead of emptying.
  • Eraser: each touch hides or shows an object; hidden objects appear as ghosts. No ring and no point creation; dragging still moves. Esc or the button leave it.
  • Properties: Visible object checkbox; the “Choose an object…” list finds hidden objects.
  • Internal objects of DGPad macros and auxiliary objects of GeoGebra have neither dot nor ghost.

Names

  • Only points show their name when created. at the end of the line, or Show name in the properties, shows it for other objects.
  • A name can be dragged around its object (at most 80 px from a point) and then keeps its relative place when the object changes.
  • Touching a name without dragging it makes it editable in place: Enter or a touch elsewhere confirm, Esc cancels, hides it. An empty or taken name is refused.

Angle marks

The arc of an angle, or its right angle mark, can be dragged to change its radius (5 to 200 px).

Filtering the list

, in the header of the “Construction” panel, opens a menu that shows only some of the lines:

  • all objects, visible objects or hidden objects;
  • Linked to the selection: the selected objects, what they depend on and what depends on them;
  • one or more types of objects present in the figure (points, lines, circles…), with their number.

Each active filter shows as a tag below the header; clicking it removes the filter. The number of objects becomes “38 / 2569”. Filters only change the list, not the figure, and are not saved.

Values

writes under each line the value of the object in a formula: coordinates, length, radius, area, angle measure in degrees, value of an expression. The values follow the moves.

Step by step

replays the construction: each visible object is a step, a hidden object joins the previous step. A bar replaces the input:

Button Key Effect
Home End first, last step
← → previous, next step
play, one step per second

Touching a line goes to its step. Points can still be moved, nothing is built. Esc, the button, a tool, the eraser, the properties or undo leave it. The saved figure is not affected.
