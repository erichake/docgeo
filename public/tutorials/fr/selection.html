Construire par sélection multiple

Les objets d’abord, l’outil ensuite : les objets sélectionnés deviennent les arguments de l’outil choisi dans la palette.

Étapes

  1. Sélectionner les objets : Ctrl-clic, Maj-clic ou appui long (0,7 s). Chacun brille en bleu avec son rang. Si l’anneau d’un objet est ouvert, cet objet devient le premier de la sélection.
  2. Ouvrir la palette : les outils qui n’acceptent pas la sélection sont grisés. Survoler un outil affiche dans la consigne la ligne qu’il écrira ; si la sélection lui suffit, l’objet apparaît en pâle.
  3. Choisir l’outil : chaque objet, dans l’ordre de la sélection, prend la première place libre de son type.

Sélection complète ou incomplète

  • Sélection complète : la ligne est écrite aussitôt.
  • Sélection incomplète : l’outil attend les arguments manquants, désignés ensuite dans la figure.
  • Un nombre (rayon, angle, rapport, nombre de côtés) ne se sélectionne pas : l’outil prend une valeur par défaut, que l’on change ensuite dans sa ligne.
  • L’outil reste ensuite actif, comme choisi dans la palette sans sélection.

Cas particuliers

Outil Sélection Résultat
Polygone trois sommets ou plus polygone fermé aussitôt ; avec moins, l’outil attend les sommets suivants
Intersection deux objets le point d’intersection le plus proche de l’endroit où le second a été sélectionné
Point un objet point sur cet objet, à l’endroit où il a été sélectionné
Lieu un point son lieu ; le point sur objet dont il dépend est trouvé seul
