Formules et programmes

Le langage des expressions est celui de DGPad. DocGeo l’interprète lui-même : il n’est jamais exécuté comme du JavaScript.

Dans le plan, un point est un complexe : (A + B)/2 est le milieu, 2*B - A le symétrique de A par rapport à B.

Lire un autre onglet

Dans un classeur, une formule lit la valeur d’un objet d’un autre onglet, comme dans un tableur : le nom de l’onglet entre apostrophes, un point d’exclamation, le nom de l’objet. 

m = 'Figure 1'!c
aire = Calculs!p * 2
  • Les apostrophes sont inutiles si le nom de l’onglet n’a ni espace ni signe (Calculs!p) ; une apostrophe du nom s’écrit \' ('L\'aire'!c).
  • La valeur est celle que lirait une formule de cet onglet : coordonnées d’un point, longueur d’un segment… Une fonction ne se lit pas.
  • Lecture seule : rien dans un onglet ne modifie un autre onglet. La valeur est relue quand on revient sur l’onglet qui la lit. Seule exception : les globales des programmes, communes à tout le classeur.
  • Un onglet ne peut pas se lire lui-même, ni lire un onglet qui le lit (« Référence circulaire »). Un onglet ou un objet inconnu est refusé à la saisie.
  • Renommer un onglet, ou un objet de l’onglet montré, met à jour les formules des autres onglets. Après la suppression d’un onglet, les formules qui le lisaient sont indéfinies.

Programmes

Instructions séparées par ; ou des sauts de ligne ; la dernière donne la valeur.

variables var s = 0 (let, const) ; s += 2, -=, *=, /=, L[2] = 5
conditions if (a > 0) { … } else { … }
boucles for (var k = 0; k < 10; k++) { … }, while (…) { … }, break, continue
fonctions function carre(u) { return u*u }
listes L.push(P), L.pop(), L.concat(M), L.join(", ")
globales GLOBAL_SET("n", 5), GLOBAL_INC("n", 1), GLOBAL_GET("n")
pause WAIT(500) : 500 ms, dans le programme d’un bouton

Les variables d’un programme masquent les objets de même nom. Une boucle sans fin est interrompue. Les globales sont partagées par tous les programmes de la figure, ses boutons compris.

Méthodes des objets

S.setHidden(1), S.setShowName(1) cacher, afficher le nom (0 : l’inverse)
S.setRGBColor(r, g, b), S.setOpacity(o), S.setSize(t) couleur (0 à 255), opacité (0 à 1), taille ou épaisseur
a.setPrecision(n), a.setIncrement(p) décimales, pas d’un curseur
P.getX(), P.getY(), P.coords3D(), P.coords2D() coordonnées ; coordonnées à l’écran
S.getName(), c.center() nom, centre d’un cercle 
if (a < 0) {
    p.setRGBColor(220, 38, 38)

    p.setRGBColor(37, 99, 235)

Un programme est parent des objets qu’il met en forme : il est recalculé avec la figure, et une redéfinition qui créerait un cycle est refusée.
