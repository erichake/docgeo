Construire au clavier

Une ligne par objet : nom = Commande(arguments), tapée dans la ligne de saisie du panneau « Construction » et validée par Entrée. 

A = (-5, -2)
B = (4, -3)
C = (-1, 4)
p = Polygone(A, B, C)
c = CercleCirconscrit(A, B, C)
M = Milieu(A, B)

Syntaxe

Élément Règle
Point libre A = (2, 3) ; A = (2, 3, 1) en 3D
Coordonnées polaires P = (3; 60°) : rayon et angle séparés par un point-virgule
Vecteur libre u = (2, 1) : nom en minuscule ; tracé depuis l’origine, il se glisse par sa pointe
Nombres séparateur décimal : le point (2.5) ; (1,5, 2) est un point à trois coordonnées
Commande sans casse ni accents (mediatrice(A, B)), nom anglais accepté ; la ligne est réécrite dans la forme usuelle
Nombre en argument nombre, nom d’expression ou de curseur, ou formule : Cercle(A, 2*r)
Nom omis Milieu(A, B) : nom automatique, majuscule pour un point, u, v, w pour un vecteur, lettre grecque pour un angle, minuscule sinon (ni e, i, k, l, o, t, x, y, z)
Nom inconnu commençant par une minuscule, il devient un curseur : A = (a, 4), d = y = m x + p
Nom existant la ligne redéfinit l’objet
Nom spécial apostrophe admise (A') ; autres caractères entre accents graves (`aux 2`)
Noms à éviter x, y (équations), i (unité imaginaire)
Autre ligne ni point ni commande : une expression (a = 3, E = d(A, B))

Formes et arguments de chaque commande : Les commandes.

Complétion et désignation

  • La liste propose les commandes en tête de ligne, puis, entre parenthèses, les seuls objets acceptés par l’argument en cours, mis en évidence dans la figure. ↑ ↓ choisissent, Tab ou Entrée insèrent, Échap ferme.
  • Un clic sur un objet écrit son nom, suivi de , ou ) selon ce qui reste à désigner : M = Milieu(, clic sur A, clic sur B donne M = Milieu(A, B).
  • Dans la ligne de saisie, un clic là où il n’y a pas de point en crée un (libre, sur objet ou intersection) ; un aperçu suit le pointeur. Recliquer le premier sommet d’un polygone le termine.
  • Même geste dans une formule : E = d(, clic sur H puis M.

Modifier une ligne

Chaque ligne du panneau est un champ : Entrée valide, Échap rétablit.

  • Nouvelles coordonnées : le point libre est déplacé.
  • Nouvelle définition : l’objet est redéfini, garde son style, et ses dépendants suivent (M = Milieu(A, B) → M = (5, 5) → M = Milieu(B, C)). La construction est réordonnée si besoin ; un cycle est refusé.
  • Nouveau nom : l’objet est renommé dans toutes les lignes et formules.
  • A = supprime A et ses dépendants.

Équations

Deux membres en x, y (et z) séparés par = ; la nature se lit dans les coefficients, qui peuvent dépendre de curseurs.

Ligne Objet
d = y = a*x + b, x = 3 droite
c = x^2 + y^2 = 4 cercle
e = x^2/9 + y^2/4 = 1 conique
p = x + y + z = 3 plan (3D)

Degré supérieur à 2 ou non polynomial : refusé. En tête de ligne, z est un nom : z = 3 est une expression, le plan s’écrit p = z = 3.

Intersections et points sur objet

  • Intersection(d1, d2) pour deux droites ; Intersection(c, d, n), n de 1 à 4, sinon.
  • AutreIntersection(c, d, P) : le point commun le plus éloigné de P.
  • Point(c, t), ou Point(p, a, b) sur un polygone ou une conique : position sur l’objet, écrite par le geste.

Erreurs

Une ligne fautive n’est pas appliquée : elle reste encadrée de rouge, la consigne donne la raison, le reste de la figure est intact.

Message Cause
Écriture incomprise parenthèse, virgule ou caractère
Commande inconnue, Objet inconnu nom mal orthographié ou absent
Arguments incorrects pour … aucune forme ne correspond ; « Avec ces arguments » rappelle les formes
Le nom … est déjà pris renommage
Un objet ne peut dépendre de lui-même cycle
Une figure plane garde ses objets dans le plan z = 0… objet de l’espace : passer en vue 3D
Cet objet ne s’écrit pas encore en texte objet importé sans commande : ligne nom = … en lecture seule
