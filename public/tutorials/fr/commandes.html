Les commandes

  • Nom sans casse ni accents ; le nom anglais, en petit, est accepté dans toutes les langues.
  • A, B, O, P : points ; d : droite, segment ou demi-droite ; c : cercle ou courbe ; p : polygone ou plan ; s : segment ou solide ; u : vecteur.
  • L : liste de points (voir Listes de points) ; un point s’écrit aussi dans l’argument : (2, 3), Point(A + [1, 0]), L(2).
  • r, a, k, f : nombre, expression, curseur ou formule (Cercle(O, 2*r)) ; n, t : nombres écrits.
  • L’icône est celle de l’outil de la palette ; 3D : formes de l’espace.

Transformations

Ce qui définit la transformation d’abord, puis P, un point ou un objet : segment, droite, polygone, cercle, conique, courbe… ; en 3D aussi un plan, une sphère, un polyèdre (sauf Inversion). L’image d’un objet est un objet de même nature, sinon un lieu (voir Transformer un objet) : t2 = Symétrie(d, t). L’ordre de GeoGebra (P d’abord) n’est pas accepté.

Côtés des polygones

Côté · Cliquez près d’un côté pour utiliser les outils des segments ; cliquez à l’intérieur pour sélectionner le polygone.

Dans un argument, Côté(p, k) désigne le côté numéro k, à partir de 1 dans l’ordre des sommets, sans ajouter de segment à la construction. Cela fonctionne aussi pour les polygones réguliers. 

M = Milieu(Côté(p, 2))

Faces des polyèdres

Face · Un outil qui attend un plan ou un polygone, ou qui pose un point, prend la face visible sous le pointeur ; sans outil, un clic sélectionne le polyèdre.

Dans un argument, Face(k, n) désigne la face numéro n, à partir de 1, sans ajouter d’objet à la construction. La base d’un prisme ou d’une pyramide est la face 1. Une face se comporte comme un polygone : on y pose un point, et elle sert de plan aux outils de l’espace. Une droite ne la coupe qu’à l’intérieur de la face. En 3D, tout polygone sert ainsi de plan. 

d = Perpendiculaire(O, Face(k, 1))
