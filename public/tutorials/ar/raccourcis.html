الاختصارات والإيماءات

لوحة المفاتيح

Ctrl S حفظ
Ctrl Shift S حفظ باسم
Ctrl O فتح
Ctrl Z؛ Ctrl Shift Z، Ctrl Y تراجع؛ إعادة
Delete، ⌫ حذف العنصر أو التحديد
Esc ترك الأداة، إغلاق الحلقة، إفراغ التحديد، الخروج من الممحاة أو المغانط أو خطوة بخطوة، ثم إغلاق الخصائص أو لوحة الأدوات
P، S (الأبعاد الثلاثة) المنظور، الأرضية
← → Home End خطوات وضع خطوة بخطوة

الأسطر النصية

Enter تأكيد؛ إدراج الإكمال المُبرز
Esc إغلاق الإكمال، وإلا استعادة السطر
↑ ↓، Tab التصفح، إدراج الإكمال
النقر على عنصر كتابة اسمه

البرامج (التعريف)

Ctrl Enter تطبيق، إنشاء
Enter، Tab، } سطر مُزاح، إزاحة، إلغاء الإزاحة
Esc استعادة النص المطبَّق

الفأرة والإصبع

لمس مكان فارغ / تقاطع / عنصر، واللوحة مغلقة نقطة حرة / تقاطع / تحديد وحلقة
Ctrl-نقر، Shift-نقر، ضغط مطوّل تحديد متعدد
Shift-نقر أثناء أداة إبقاء الوسيط حتى مغادرة الأداة
سحب مكان فارغ؛ الزر الأيمن تحريك العرض؛ في الأبعاد الثلاثة، الزر الأيمن يدوّر
إصبع واحد في مكان فارغ تحريك العرض؛ التدوير في الأبعاد الثلاثة
عجلة الفأرة، لوحة اللمس تكبير
القرص بإصبعين التكبير حول منتصف المسافة بين الإصبعين
سحب اسم أو علامة زاوية أو تعبير وضعه في مكانه؛ تغيير نصف قطر القوس
لمس اسم إعادة التسمية
إصبع ضاغط أثناء استعمال أداة التصويب، والتحديد عند الرفع
السحب على حقل عددي الضبط (Shift: بدقة)
حافة لوحة تغيير الحجم؛ نقر مزدوج: العرض الافتراضي
علامة تبويب صفحة نقر مزدوج: إعادة التسمية؛ نقر بالزر الأيمن: قائمة الصفحة؛ سحب: نقل (المصنفات)
