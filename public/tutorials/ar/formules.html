قراءة صفحة أخرى

في مصنف، تقرأ الصيغة قيمة عنصر من صفحة أخرى، كما في جدول البيانات: اسم الصفحة بين علامتي اقتباس مفردتين، ثم علامة تعجب، ثم اسم العنصر. 

m = 'الصفحة 1'!c
s = بيانات!p * 2
  • لا حاجة إلى علامتي الاقتباس إن لم يكن في اسم الصفحة مسافة ولا رمز (بيانات!p)؛ وتُكتب الفاصلة العليا في الاسم \' ('Tom\'s'!c).
  • القيمة هي التي تقرؤها صيغة من تلك الصفحة: إحداثيات نقطة، طول قطعة مستقيمة… ولا تُقرأ الدالة.
  • للقراءة فقط: لا شيء في صفحة يغيّر صفحة أخرى. وتُقرأ القيمة من جديد عند العودة إلى الصفحة التي تقرؤها. الاستثناء الوحيد: المتغيرات العامة للبرامج، المشتركة بين المصنف كله.
  • لا يمكن لصفحة أن تقرأ نفسها، ولا أن تقرأ صفحة تقرؤها («مرجع دائري»). وتُرفض عند الكتابة صفحةٌ أو عنصرٌ غير معروف.
  • إعادة تسمية صفحة، أو عنصر من الصفحة المعروضة، تحدّث صيغ الصفحات الأخرى. وبعد حذف صفحة، تصبح الصيغ التي كانت تقرؤها غير معرّفة.

البرامج

تعليمات يفصل بينها ; أو فواصل الأسطر؛ وآخرها يعطي القيمة.

المتغيرات var s = 0 (let، const)؛ s += 2، -=، *=، /=، L[2] = 5
الشروط if (a > 0) { … } else { … }
الحلقات for (var k = 0; k < 10; k++) { … }، while (…) { … }، break، continue
الدوال function square(u) { return u*u }
القوائم L.push(P)، L.pop()، L.concat(M)، L.join(", ")
المتغيرات العامة GLOBAL_SET("n", 5), GLOBAL_INC("n", 1), GLOBAL_GET("n")
إيقاف مؤقت WAIT(500): 500 ms، في برنامج زر

تحجب متغيرات البرنامج العناصر التي تحمل الاسم نفسه. وتُقطع الحلقة التي لا تنتهي. تشترك جميع برامج الشكل، بما فيها أزراره، في المتغيرات العامة.

طرائق العناصر

S.setHidden(1)، S.setShowName(1) إخفاء، إظهار الاسم (0: العكس)
S.setRGBColor(r, g, b)، S.setOpacity(o)، S.setSize(t) اللون (من 0 إلى 255)، العتامة (من 0 إلى 1)، الحجم أو السمك
a.setPrecision(n)، a.setIncrement(p) الأرقام العشرية، خطوة منزلقة
P.getX()، P.getY()، P.coords3D()، P.coords2D() الإحداثيات؛ الإحداثيات على الشاشة
S.getName()، c.center() الاسم، مركز دائرة

} else {
