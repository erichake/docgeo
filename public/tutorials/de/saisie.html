Mit der Tastatur konstruieren

Eine Zeile pro Objekt: Name = Befehl(Argumente), in die Eingabezeile des Feldes „Konstruktion“ getippt und mit Eingabe bestätigt. 

A = (-5, -2)
B = (4, -3)
C = (-1, 4)
p = Vieleck(A, B, C)
c = Umkreis(A, B, C)
M = Mittelpunkt(A, B)

Syntax

Element Regel
Freier Punkt A = (2, 3); A = (2, 3, 1) in 3D
Polarkoordinaten P = (3; 60°): Radius und Winkel, durch ein Semikolon getrennt
Freier Vektor u = (2, 1): kleingeschriebener Name; vom Ursprung aus gezeichnet, wird er an seiner Spitze gezogen
Zahlen Dezimaltrennzeichen: der Punkt (2.5); (1,5, 2) ist ein Punkt mit drei Koordinaten
Befehl ohne Groß- und Kleinschreibung und Akzente (mittelsenkrechte(A, B)), der englische Name wird akzeptiert; die Zeile wird in der üblichen Form neu geschrieben
Zahl als Argument Zahl, Name eines Ausdrucks oder Schiebereglers, oder Formel: Kreis(A, 2*r)
Name weggelassen Mittelpunkt(A, B): automatischer Name, großgeschrieben für einen Punkt, u, v, w für einen Vektor, ein griechischer Buchstabe für einen Winkel, sonst kleingeschrieben (weder e, i, k, l, o, t, x, y noch z)
Unbekannter Name beginnt er mit einem Kleinbuchstaben, wird er zu einem Schieberegler: A = (a, 4), d = y = m x + p
Vorhandener Name die Zeile definiert das Objekt neu
Besonderer Name Apostroph erlaubt (A'); andere Zeichen zwischen Backticks (`aux 2`)
Zu vermeidende Namen x, y (Gleichungen), i (imaginäre Einheit)
Andere Zeile weder Punkt noch Befehl: ein Ausdruck (a = 3, E = d(A, B))

Formen und Argumente jedes Befehls: Die Befehle.

Vervollständigung und Auswahl

  • Die Liste schlägt am Zeilenanfang die Befehle vor, dann zwischen den Klammern nur die Objekte, die das aktuelle Argument annimmt, hervorgehoben in der Figur. ↑ ↓ wählen, Tab oder Eingabe fügen ein, Esc schließt.
  • Ein Klick auf ein Objekt schreibt seinen Namen, gefolgt von , oder ), je nachdem, was noch zu wählen ist: M = Mittelpunkt(, Klick auf A, Klick auf B ergibt M = Mittelpunkt(A, B).
  • In der Eingabezeile erzeugt ein Klick dort, wo kein Punkt ist, einen (frei, auf Objekt oder Schnittpunkt); eine Vorschau folgt dem Zeiger. Ein erneuter Klick auf die erste Ecke eines Vielecks schließt es ab.
  • Dieselbe Geste in einer Formel: E = d(, Klick auf H, dann auf M.

Eine Zeile bearbeiten

Jede Zeile des Feldes ist ein Eingabefeld: Eingabe bestätigt, Esc stellt wieder her.

  • Neue Koordinaten: Der freie Punkt wird verschoben.
  • Neue Definition: Das Objekt wird neu definiert, behält seinen Stil, und seine abhängigen Objekte folgen (M = Mittelpunkt(A, B) → M = (5, 5) → M = Mittelpunkt(B, C)). Die Konstruktion wird bei Bedarf neu geordnet; ein Zyklus wird abgelehnt.
  • Neuer Name: Das Objekt wird in allen Zeilen und Formeln umbenannt.
  • A = löscht A und seine abhängigen Objekte.
  • Langer Befehl: öffnet ihn im Abschnitt Definition der Eigenschaften, auf mehreren Zeilen, mit derselben Vervollständigung; ein Klick auf ein Objekt der Figur fügt seinen Namen ein, ⌘-Eingabe übernimmt.

Gleichungen

Zwei Seiten in x, y (und z), getrennt durch =; die Art des Objekts ergibt sich aus den Koeffizienten, die von Schiebereglern abhängen dürfen.

Zeile Objekt
d = y = a*x + b, x = 3 Gerade
c = x^2 + y^2 = 4 Kreis
e = x^2/9 + y^2/4 = 1 Kegelschnitt
p = x + y + z = 3 Ebene (3D)

Grad über 2 oder nicht polynomial: abgelehnt. Am Zeilenanfang ist z ein Name: z = 3 ist ein Ausdruck, die Ebene schreibt sich p = z = 3.

Schnittpunkte und Punkte auf Objekten

  • Schnittpunkt(d1, d2) für zwei Geraden; Schnittpunkt(c, d, n), n von 1 bis 4, sonst; in 3D Schnittpunkt(d, s, n), n = 1 oder 2, für eine Gerade und eine Kugel, einen Zylinder oder einen Kegel.
  • AndererSchnittpunkt(c, d, P): der gemeinsame Punkt, der am weitesten von P entfernt ist.
  • Punkt(c, t) oder Punkt(p, a, b) auf einem Vieleck oder einem Kegelschnitt: Position auf dem Objekt, von der Geste geschrieben. a und b sind Koordinaten in einem Koordinatensystem des Objekts (siehe Die Befehle).

Fehler

Eine fehlerhafte Zeile wird nicht übernommen: Sie bleibt rot umrandet, der Hinweis nennt den Grund, der Rest der Figur bleibt unverändert.

Meldung Ursache
Unverständliche Eingabe Klammer, Komma oder Zeichen
Unbekannter Befehl, Unbekanntes Objekt Name falsch geschrieben oder nicht vorhanden
Ungültige Argumente für … keine Form passt; „Mit diesen Argumenten“ nennt die Formen
Der Name … ist bereits vergeben Umbenennung
Ein Objekt kann nicht von sich selbst abhängen Zyklus
