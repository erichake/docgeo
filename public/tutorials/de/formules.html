Eine andere Seite lesen

In einer Arbeitsmappe liest eine Formel den Wert eines Objekts einer anderen Seite, wie in einer Tabellenkalkulation: der Name der Seite in Apostrophen, ein Ausrufezeichen, der Name des Objekts. 

m = 'Seite 1'!c
fläche = Daten!p * 2
  • Die Apostrophe sind unnötig, wenn der Seitenname weder Leerzeichen noch Zeichen enthält (Daten!p); ein Apostroph im Namen wird \' geschrieben ('Tom\'s'!c).
  • Der Wert ist der, den eine Formel dieser Seite lesen würde: Koordinaten eines Punktes, Länge einer Strecke… Eine Funktion kann nicht gelesen werden.
  • Nur lesend: Nichts auf einer Seite ändert eine andere Seite. Der Wert wird neu gelesen, wenn man zu der Seite zurückkehrt, die ihn liest.
  • Eine Seite kann weder sich selbst lesen noch eine Seite, die sie liest („Zirkelbezug“). Eine unbekannte Seite oder ein unbekanntes Objekt wird bei der Eingabe abgelehnt.
  • Das Umbenennen einer Seite oder eines Objekts der angezeigten Seite passt die Formeln der anderen Seiten an. Nach dem Löschen einer Seite sind die Formeln, die sie lasen, undefiniert.

Programme

Anweisungen, getrennt durch ; oder Zeilenumbrüche; die letzte liefert den Wert.

Variablen var s = 0 (let, const); s += 2, -=, *=, /=, L[2] = 5
Bedingungen if (a > 0) { … } else { … }
Schleifen for (var k = 0; k < 10; k++) { … }, while (…) { … }, break, continue
Funktionen function quadrat(u) { return u*u }
Listen L.push(P), L.pop(), L.concat(M), L.join(", ")
Globale GLOBAL_SET("n", 5), GLOBAL_INC("n", 1), GLOBAL_GET("n")
Pause WAIT(500): 500 ms, im Programm einer Schaltfläche

Die Variablen eines Programms verdecken Objekte gleichen Namens. Eine Endlosschleife wird abgebrochen. Globale werden von allen Programmen der Figur geteilt, auch von ihren Schaltflächen.

Ein Programm ist Elternobjekt der Objekte, die es gestaltet: Es wird mit der Figur neu berechnet, und eine Neudefinition, die einen Zyklus erzeugen würde, wird abgelehnt.
