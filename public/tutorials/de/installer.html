DocGeo installieren

In Chrome und Edge lässt sich der DocGeo-Editor unter macOS, Windows oder Linux wie eine Anwendung auf dem Computer installieren. Dafür sind weder Administratorrechte noch ein Download nötig.

Installieren

  1. Öffnen Sie den Editor in Chrome oder Edge.
  2. Wählen Sie Datei › DocGeo auf diesem Computer installieren…
  3. Bestätigen Sie mit Installieren: DocGeo öffnet sich sofort in einem eigenen Fenster.

Dieser Eintrag erscheint nur, wenn der Browser die Installation anbietet: nicht im bereits installierten DocGeo, nicht in Firefox oder Safari. Der Browser bietet sie auch über ein Symbol rechts in der Adressleiste an.

Was man gewinnt

  • DocGeo hat ein eigenes Fenster, ohne Adressleiste und Tabs, und startet wie ein Programm aus dem Dock, dem Startmenü oder dem Anwendungsmenü.
  • Es funktioniert ohne Internetverbindung (Ohne Verbindung).
  • Ein Doppelklick auf eine .dgo-, .dgp- oder .ggb-Figur öffnet sie in DocGeo (Eine Figur per Doppelklick öffnen).

Ohne Verbindung

Nach einem ersten Öffnen online startet und arbeitet DocGeo ohne Verbindung: konstruieren, Dateien auf dem Computer öffnen und speichern. Nur über einen Link geöffnete Figuren (Eine Figur per Link teilen) und dieses Handbuch brauchen eine Verbindung.

Eine Figur per Doppelklick öffnen

Das installierte DocGeo öffnet .dgo-, .dgp- und .ggb-Dateien: Ein Doppelklick zeigt die Datei in einem DocGeo-Fenster. Eine so geöffnete .dgo-Figur wird wieder in ihre Datei gespeichert.

Öffnet bereits ein anderes Programm diese Dateien (DGPad, GeoGebra…), wählen Sie einmalig DocGeo: auf dem Mac im Finder Informationen › Öffnen mit, DocGeo, dann Alle ändern; unter Windows Rechtsklick auf die Datei, Öffnen mit.

Aktualisierungen

DocGeo aktualisiert sich selbst. Eine neue Version wird beim Öffnen von DocGeo geladen und gilt ab dem nächsten Start, wenn alle seine Fenster geschlossen waren. Ohne Verbindung arbeitet DocGeo mit seiner vorhandenen Version weiter.

Deinstallieren

Öffnen Sie im DocGeo-Fenster das Browsermenü ⋮, dann DocGeo deinstallieren. Unter Windows lässt sich DocGeo auch über Einstellungen › Apps deinstallieren. Ihre Figuren bleiben unberührt.

In Firefox und Safari

Firefox installiert DocGeo nicht: Man verwendet es in einem Tab. Safari auf dem Mac kann es ins Dock legen (Ablage › Zum Dock hinzufügen), in einem eigenen Fenster, aber ohne Öffnen der Figuren per Doppelklick.
