Import aus DGPad und GeoGebra

.dgo ist das Format von DocGeo; .dgp und .ggb werden importiert und dann als .dgo gespeichert. Kein Export nach DGPad oder GeoGebra.

Das Format .dgo

Komprimiertes JSON: Objekte, Stile und Ansicht. Es entwickelt sich nur durch Ergänzungen weiter: Eine gespeicherte Datei bleibt in späteren Versionen lesbar.

DGPad

Ebene und 3D-Figuren, Stile, Ausdrücke, Schieberegler, Animationen, Ortslinien, Magnete, Spuren und Makros werden übernommen.

Programm in DGPad DocGeo
Skripte von Ausdrücken, Blockly, das einen Ausdruck berechnet, Blockly-Schildkröte interpretiert
Blockly-Schaltflächen (Gestaltung, Ändern einer Zahl) interpretiert
Ereignis-Blockly, JavaScript, aktives HTML ignoriert und gemeldet
Ausdruck „restrictions“ (Sperren der Oberfläche) ignoriert
Einschränkungen der 3D-Drehung angewendet

Kein Code einer Figur wird vom Browser ausgeführt. Bewusste Abweichung: Eine Kurve wird an ihren Unstetigkeitsstellen nicht durch eine senkrechte Linie verbunden.

GeoGebra

Jeder Befehl wird zum entsprechenden DocGeo-Objekt, mit denselben Argumenten; Punkte auf Objekten und Schnittpunkte werden an die von GeoGebra gespeicherten Positionen gesetzt.

  • Übernommen: ebene und räumliche Geometrie, Funktionen und Kurven (numerische Ableitungen und Integrale), Schieberegler, Kontrollkästchen, Eingabefelder, Anzeigebedingungen, LaTeX-Texte, Bilder, Stile und Position der Namen, Achsen und Gitter, Animationen, Spuren, Makros.
  • Nicht übernommen: Skripte (GGBScript, JavaScript), Computeralgebra, einige Listenbefehle.

Mehr als die Hälfte der 470 Figuren eines Korpus von geogebra.org öffnen sich ohne Verlust. Ein nicht unterstütztes Element wird samt seinen abhängigen Objekten ignoriert und gemeldet.
