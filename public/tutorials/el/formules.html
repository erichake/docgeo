Τύποι και προγράμματα

Η γλώσσα των εκφράσεων είναι αυτή του DGPad. Το DocGeo την ερμηνεύει μόνο του: δεν εκτελείται ποτέ ως JavaScript.

Τιμές

Γραφή Τιμή
3, -2.5, .5, 2e3 αριθμοί (δεκαδική τελεία)
PI, π π (το pi δεν αναγνωρίζεται)
1 + 2i μιγαδικός αριθμός
30° γωνία σε μοίρες, μετατρεπόμενη στη μονάδα γωνιών του σχήματος
"κείμενο" κείμενο· το + συνενώνει
[1, 2, 3] λίστα· [x, y], [x, y, z]: σημείο ή διάνυσμα
A σημείο: συντεταγμένες· τμήμα: μήκος· κύκλος: ακτίνα· πολύγωνο: εμβαδόν· γωνία: μέτρο
x, y, z, t μεταβλητές μιας συνάρτησης

Στο επίπεδο, ένα σημείο είναι μιγαδικός αριθμός: το (A + B)/2 είναι το μέσο, το 2*B - A το συμμετρικό του A ως προς το B.

Τελεστές

+ - * / ^ % πράξεις, δύναμη, υπόλοιπο
2x, 2π, 3(x + 1) έμμεσος πολλαπλασιασμός
== != < <= > >= συγκρίσεις, με τιμή 1 ή 0· το == ανέχεται τα σφάλματα στρογγυλοποίησης
&& || ! και, ή, όχι
test ? a : b συνθήκη
L[0], A[1] στοιχείο, συντεταγμένη (από το 0)
L.length μήκος μιας λίστας

Προγράμματα

Εντολές χωρισμένες με ; ή αλλαγές γραμμής· η τελευταία δίνει την τιμή.

μεταβλητές var s = 0 (let, const)· s += 2, -=, *=, /=, L[2] = 5
συνθήκες if (a > 0) { … } else { … }
βρόχοι for (var k = 0; k < 10; k++) { … }, while (…) { … }
συναρτήσεις function tetragono(u) { return u*u }
λίστες L.push(P), L.pop(), L.concat(M), L.join(", ")

Οι μεταβλητές ενός προγράμματος επισκιάζουν τα αντικείμενα με το ίδιο όνομα. Ένας ατέρμονος βρόχος διακόπτεται.

Μέθοδοι των αντικειμένων

S.setHidden(1), S.setShowName(1) απόκρυψη, εμφάνιση ονόματος (0: το αντίθετο)
S.setRGBColor(r, g, b), S.setOpacity(o), S.setSize(t) χρώμα (0 έως 255), αδιαφάνεια (0 έως 1), μέγεθος ή πάχος
a.setPrecision(n), a.setIncrement(p) δεκαδικά ψηφία, βήμα δρομέα
P.getX(), P.getY(), P.coords3D(), P.coords2D() συντεταγμένες· συντεταγμένες στην οθόνη
S.getName(), c.center() όνομα, κέντρο κύκλου 
if (a < 0) {
    p.setRGBColor(220, 38, 38)
} else {
    p.setRGBColor(37, 99, 235)
};
"a = " + a

Ένα πρόγραμμα είναι γονέας των αντικειμένων που μορφοποιεί: ξαναϋπολογίζεται μαζί με το σχήμα, και ένας επαναορισμός που θα δημιουργούσε κύκλο εξαρτήσεων απορρίπτεται.
