Τύποι και προγράμματα

Η γλώσσα των εκφράσεων είναι αυτή του DGPad. Το DocGeo την ερμηνεύει μόνο του: δεν εκτελείται ποτέ ως JavaScript.

Τιμές

Γραφή Τιμή
3, -2.5, .5, 2e3 αριθμοί (δεκαδική τελεία)
PI, π π (το pi δεν αναγνωρίζεται)
1 + 2i μιγαδικός αριθμός
30° γωνία σε μοίρες, μετατρεπόμενη στη μονάδα γωνιών του σχήματος
"κείμενο" κείμενο· το + συνενώνει
[1, 2, 3] λίστα· [x, y], [x, y, z]: σημείο ή διάνυσμα
A σημείο: συντεταγμένες· τμήμα: μήκος· κύκλος: ακτίνα· πολύγωνο: εμβαδόν· γωνία: μέτρο
x, y, z, t μεταβλητές μιας συνάρτησης

Στο επίπεδο, ένα σημείο είναι μιγαδικός αριθμός: το (A + B)/2 είναι το μέσο, το 2*B - A το συμμετρικό του A ως προς το B.

Ανάγνωση άλλης καρτέλας

Σε ένα βιβλίο εργασίας, ένας τύπος διαβάζει την τιμή ενός αντικειμένου άλλης καρτέλας, όπως σε ένα υπολογιστικό φύλλο: το όνομα της καρτέλας σε απλά εισαγωγικά, ένα θαυμαστικό, το όνομα του αντικειμένου. 

m = 'Σχήμα 1'!c
εμβαδόν = Δεδομένα!p * 2
  • Τα εισαγωγικά δεν χρειάζονται αν το όνομα της καρτέλας δεν έχει κενά ούτε σύμβολα (Δεδομένα!p)· μια απόστροφος του ονόματος γράφεται \' ('Tom\'s'!c).
  • Η τιμή είναι αυτή που θα διάβαζε ένας τύπος εκείνης της καρτέλας: συντεταγμένες ενός σημείου, μήκος ενός ευθύγραμμου τμήματος… Μια συνάρτηση δεν διαβάζεται.
  • Μόνο ανάγνωση: τίποτα σε μια καρτέλα δεν αλλάζει άλλη καρτέλα. Η τιμή διαβάζεται ξανά όταν επιστρέφετε στη καρτέλα που τη διαβάζει. Μόνη εξαίρεση: οι καθολικές των προγραμμάτων, κοινές σε όλο το βιβλίο εργασίας.
  • Μια καρτέλα δεν μπορεί να διαβάσει τον εαυτό της, ούτε μια καρτέλα που τη διαβάζει («Κυκλική αναφορά»). Μια άγνωστη καρτέλα ή ένα άγνωστο αντικείμενο απορρίπτεται κατά την πληκτρολόγηση.
  • Η μετονομασία μιας καρτέλας, ή ενός αντικειμένου της εμφανιζόμενης καρτέλας, ενημερώνει τους τύπους των άλλων καρτελών. Μετά τη διαγραφή μιας καρτέλας, οι τύποι που τη διάβαζαν είναι απροσδιόριστοι.

Ανάγνωση κελιού του υπολογιστικού φύλλου

Σε μια καρτέλα με προβολή υπολογιστικού φύλλου, ένας τύπος διαβάζει τα κελιά της μέσω του ονόματος του φύλλου: ένα κελί, μια περιοχή (λίστα) ή το κελί άλλης καρτέλας. 

r = Φύλλο1!B3
L = Φύλλο1!B2:B21
k = 'Υπολογιστικό φύλλο 1'!Φύλλο1!A1

Ένα κενό κελί ή ένα κελί με σφάλμα δίνει απροσδιόριστη τιμή. Αντίστροφα, ένα κελί διαβάζει ένα αντικείμενο του σχήματος με =GEO("όνομα") (GEO).

Προγράμματα

Εντολές χωρισμένες με ; ή αλλαγές γραμμής· η τελευταία δίνει την τιμή.

μεταβλητές var s = 0 (let, const)· s += 2, -=, *=, /=, L[2] = 5
συνθήκες if (a > 0) { … } else { … }
βρόχοι for (var k = 0; k < 10; k++) { … }, while (…) { … }, break, continue
συναρτήσεις function tetragono(u) { return u*u }
λίστες L.push(P), L.pop(), L.concat(M), L.join(", ")
καθολικές GLOBAL_SET("n", 5), GLOBAL_INC("n", 1), GLOBAL_GET("n")
παύση WAIT(500): 500 ms, στο πρόγραμμα ενός κουμπιού

Οι μεταβλητές ενός προγράμματος επισκιάζουν τα αντικείμενα με το ίδιο όνομα. Ένας ατέρμονος βρόχος διακόπτεται. Οι καθολικές μοιράζονται σε όλα τα προγράμματα του σχήματος, μαζί με τα κουμπιά του.

Μέθοδοι των αντικειμένων

S.setHidden(1), S.setShowName(1) απόκρυψη, εμφάνιση ονόματος (0: το αντίθετο)
S.setRGBColor(r, g, b), S.setOpacity(o), S.setSize(t) χρώμα (0 έως 255), αδιαφάνεια (0 έως 1), μέγεθος ή πάχος
a.setPrecision(n), a.setIncrement(p) δεκαδικά ψηφία, βήμα δρομέα
P.getX(), P.getY(), P.coords3D(), P.coords2D() συντεταγμένες· συντεταγμένες στην οθόνη
S.getName(), c.center() όνομα, κέντρο κύκλου 
if (a < 0) {
    p.setRGBColor(220, 38, 38)
} else {
    p.setRGBColor(37, 99, 235)
};
"a = " + a

Ένα πρόγραμμα είναι γονέας των αντικειμένων που μορφοποιεί: ξαναϋπολογίζεται μαζί με το σχήμα, και ένας επαναορισμός που θα δημιουργούσε κύκλο εξαρτήσεων απορρίπτεται.
