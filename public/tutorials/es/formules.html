Fórmulas y programas

El lenguaje de las expresiones es el de DGPad. DocGeo lo interpreta por sí mismo: nunca se ejecuta como JavaScript.

Valores

Escritura Valor
3, -2.5, .5, 2e3 números (punto decimal)
PI, π π (pi no se reconoce)
1 + 2i número complejo
30° ángulo en grados, convertido a la unidad de ángulo de la figura
"texto" texto; + concatena
[1, 2, 3] lista; [x, y], [x, y, z]: punto o vector
A punto: coordenadas; segmento: longitud; circunferencia: radio; polígono: área; ángulo: medida
x, y, z, t variables de una función

En el plano, un punto es un número complejo: (A + B)/2 es el punto medio, 2*B - A el simétrico de A respecto de B.

Operadores

+ - * / ^ % operaciones, potencia, resto
2x, 2π, 3(x + 1) multiplicación implícita
== != < <= > >= comparaciones, que valen 1 o 0; == tolera los errores de redondeo
&& || ! y, o, no
test ? a : b condición
L[0], A[1] elemento, coordenada (a partir de 0)
L.length longitud de una lista

Funciones

Función Valor
d(A, B), distance(A, B) distancia (en el espacio en 3D)
x(A), y(A) coordenadas

rotate(P, O, a), dilate(P, O, k) imagen de P por la rotación de centro O y ángulo a; por la homotecia de centro O y razón k
sqrt, abs, exp, log raíz cuadrada, valor absoluto, exponencial, logaritmo neperiano
sin, cos, tan, asin, acos, atan, atan2(y, x) en grados o radianes según el ajuste Ángulos de la figura (grados por defecto)
floor, ceil, round redondeos
min(…), max(…), gcd(a, b), isNaN(a) mínimo, máximo, MCD, prueba de valor indefinido
arg, mod, conj argumento, módulo, conjugado
dot(u, v), cross(u, v), unitVector(u), perp(u) productos escalar y vectorial, vector unitario, unitario ortogonal
pixel(), windoww(), windowh(), windowcx(), windowcy() píxeles por unidad; tamaño y centro de la ventana en unidades
theta(), phi() ángulos de la cámara 3D
f(2), f'(2), f''(2) llamada a una expresión función de x, a su derivada, a su derivada segunda

Programas

Instrucciones separadas por ; o saltos de línea; la última da el valor.

variables var s = 0 (let, const); s += 2, -=, *=, /=, L[2] = 5
condiciones if (a > 0) { … } else { … }
bucles for (var k = 0; k < 10; k++) { … }, while (…) { … }
funciones function cuadrado(u) { return u*u }
listas L.push(P), L.pop(), L.concat(M), L.join(", ")

Las variables de un programa ocultan los objetos del mismo nombre. Un bucle infinito se interrumpe.

Métodos de los objetos

S.setHidden(1), S.setShowName(1) ocultar, mostrar el nombre (0: lo contrario)
S.setRGBColor(r, g, b), S.setOpacity(o), S.setSize(t) color (0 a 255), opacidad (0 a 1), tamaño o grosor
a.setPrecision(n), a.setIncrement(p) decimales, incremento de un deslizador
P.getX(), P.getY(), P.coords3D(), P.coords2D() coordenadas; coordenadas en la pantalla
S.getName(), c.center() nombre, centro de una circunferencia 
if (a < 0) {
    p.setRGBColor(220, 38, 38)
} else {
    p.setRGBColor(37, 99, 235)
};
