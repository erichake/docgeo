常見問題

作圖

按一下建立了點，而不是開啟工具環

按一下沒有落在物件上。按 Ctrl Z，再瞄準線條。在交叉處附近，按一下會建立交點。

工具一直處於啟用狀態

選單中的工具是持續的：完成、Esc或✕ 可離開。

按一下沒有作出任何東西

某個模式處於啟用狀態：橡皮擦（藍色）、逐步構造、磁鐵，或未選工具時的屬性面板。按Esc 離開。

(2,5, 1) 得到了一個空間中的點

小數分隔符號是點：(2.5, 1)。

L = [1, 2, 3] 被拒絕

大寫名稱會建立一個點，這裡是空間中的點。請寫list = [1, 2, 3]。

pi 是未知物件

請寫 PI 或 π。

不能把物件命名為 x 或 y

在列首，它們表示方程式的開始（y = 2x + 1）。

變換多邊形

選擇變換，選取確定它的物件，再選多邊形：它的像是多邊形。要變換多個，按住 Shift 選取中心或對稱軸（變換物件）。

修改按一下建立之圓的半徑

拖曳圓，或修改其列（圓(O, r)，r 為數、滑桿或公式）。

刪除一個點時其他物件也被刪除了

依賴物件會隨之刪除。先復原，然後隱藏該點而不是刪除它。

3D 與檢視

「3D 檢視」無法返回平面

有物件離開了平面 z = 0；提示會指出該物件。

用滑鼠旋轉

右鍵；左鍵平移檢視。

在平板上縮放

雙指張開可放大圖形，合攏可縮小圖形。雙指一起拖曳可平移檢視。

軌跡顯示消失了

每次平移或縮放檢視時軌跡都會被清除。

檔案

用 ?url= 開啟的圖形無法載入

檔案必須與知道連結的任何人共用，不設密碼，且 ?url= 必須放在網址的最後（見透過連結分享圖形）。不支援學校或工作帳戶的 OneDrive 連結，也不支援拒絕自動下載的網站。

匯入不完整

列出的元素不受支援（匯入 DGPad 和 GeoGebra 圖形）；圖形的其餘部分可以正常使用和儲存。
