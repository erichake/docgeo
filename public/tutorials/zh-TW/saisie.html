用鍵盤作圖

每個物件一列：名稱 = 指令(參數)，在「作圖」面板的輸入列中輸入，按Enter 確認。 

A = (-5, -2)
B = (4, -3)
C = (-1, 4)
p = 多邊形(A, B, C)
c = 外接圓(A, B, C)
M = 中點(A, B)

語法

元素 規則
自由點 A = (2, 3)；3D 中為A = (2, 3, 1)
極座標 P = (3; 60°)：半徑和角，用分號隔開
自由向量 u = (2, 1)：名稱用小寫字母；從原點畫出，拖曳其終點即可移動
數 小數分隔符號為點（2.5）；(1,5, 2)是一個有三個座標的點
指令 不區分大小寫和重音符號，也接受英文名稱；該列會改寫為通常形式
數作為參數 數、運算式或滑桿的名稱，或公式：圓(A, 2*r)
省略名稱 中點(A, B)：自動命名，點用大寫字母，向量用 u、v、w，角用希臘字母，其他用小寫字母（不用 e、i、k、l、o、t、x、y、z）
未知名稱 以小寫字母開頭時，成為一個滑桿：A = (a, 4)、d = y = m x + p
已有名稱 該列重新定義此物件
特殊名稱 可使用撇號（A'）；其他字元放在反引號之間（`aux 2`）
應避免的名稱 x、y（方程式）、i（虛數單位）
其他列 既不是點也不是指令：一個運算式（a = 3、E = d(A, B)）

各指令的形式和參數：指令。

自動完成與選取

  • 在列首，清單提示指令；在括號內，只提示目前參數可接受的物件，並在圖形中醒目顯示。↑ ↓ 選擇，Tab 或Enter 插入，Esc關閉。
  • 點按一個物件會寫入其名稱，後面依還需選取的內容加上, 或 )：M = 中點(，點按 A，再點按 B，得到 M = 中點(A, B)。
  • 在輸入列中，點按沒有點的地方會建立一個點（自由點、物件上的點或交點）；預覽跟隨游標。再次點按多邊形的第一個頂點即可完成多邊形。
  • 在公式中也一樣：E = d(，點按 H，再點按 M。

修改一列

面板中的每一列都是一個輸入欄位：Enter確認，Esc還原。

  • 新座標：移動自由點。
  • 新定義：物件被重新定義，保留其樣式，其依賴物件隨之改變（M = 中點(A, B) → M = (5, 5) → M = 中點(B, C)）。必要時會重新排列作圖順序；循環依賴會被拒絕。
  • 新名稱：物件在所有列和公式中都會被重新命名。
  • A = 刪除 A 及其依賴物件。
  • 長指令：在屬性的定義區段中開啟它，分多列顯示，補全相同；點選圖形中的物件會插入其名稱，⌘-Enter套用。

方程式

用 = 分隔的關於 x、y（和 z）的兩邊；物件類型由係數決定，係數可以依賴於滑桿。

列 物件
d = y = a*x + b、x = 3 直線
c = x^2 + y^2 = 4 圓
e = x^2/9 + y^2/4 = 1 圓錐曲線
p = x + y + z = 3 平面（3D）

次數高於 2 或非多項式：拒絕。在列首，z是名稱：z = 3是運算式，平面應寫作p = z = 3。

交點與物件上的點

  • 兩條直線用 交點(d1, d2)；其他情況用交點(c, d, n)，n 為 1 到 4。
  • 另一交點(c, d, P)：離 P 最遠的公共點。
  • 點(c, t)，或多邊形、圓錐曲線上的點(p, a, b)：在物件上的位置，由手勢寫出。a、b 是物件的一個座標系中的座標（見指令）。

錯誤

有錯誤的列不會被套用：它保持紅框，提示給出原因，圖形的其餘部分不受影響。

訊息 原因
無法理解 括號、逗號或字元
未知指令、未知物件 名稱拼寫錯誤或不存在
… 的參數不正確 沒有相符的形式；「使用這些參數」會列出各種形式
名稱 … 已被使用 重新命名
物件不能依賴於自身 循環依賴
平面圖形的物件都在平面 z = 0 內… 空間物件：切換到 3D 檢視
此物件暫時無法寫成文字 沒有指令的匯入物件：唯讀列 名稱 = …
