安裝 DocGeo

在 Chrome 和 Edge 中，無論是 macOS、Windows 還是 Linux，DocGeo 編輯器都可以像應用程式一樣安裝到電腦上。既不需要管理員權限，也不需要下載任何軟體。

安裝

  1. 在 Chrome 或 Edge 中開啟編輯器。
  2. 選擇檔案 › 在此電腦上安裝 DocGeo…
  3. 按安裝確認：DocGeo 會立即在自己的視窗中開啟。

只有當瀏覽器提供安裝時才會出現此選單項目：已安裝的 DocGeo 中不會出現，Firefox 和 Safari 中也不會出現。瀏覽器也會透過網址列右側的圖示提供安裝。

安裝後的好處

  • DocGeo 擁有自己的視窗，沒有網址列和分頁，可以像一般軟體一樣從 Dock、開始選單或應用程式選單啟動。
  • 不需連網即可使用（離線使用）。
  • 按兩下 .dgo、.dgp 或 .ggb 圖形，即可在 DocGeo 中開啟（按兩下開啟圖形）。

離線使用

第一次連網開啟之後，DocGeo 不需連網即可開啟和使用：作圖，以及在電腦上開啟和儲存檔案。只有透過連結開啟的圖形（透過連結分享圖形）和本手冊需要連網。

按兩下開啟圖形

安裝後的 DocGeo 可以開啟 .dgo、.dgp 和 .ggb 檔案：按兩下其中任一檔案，即在 DocGeo 視窗中顯示。以這種方式開啟的 .dgo 圖形會儲存回原檔案。

如果其他軟體已經在開啟這些檔案（DGPad、GeoGebra…），請一次改為 DocGeo：在 Mac 的 Finder 中，取得資訊 › 打開檔案的應用程式，選擇 DocGeo，再按全部更改；在 Windows 中，在檔案上按右鍵，選擇開啟檔案。

Mac 上的圖形圖示

在 Mac 上，圖形的圖示是一頁紙上的 DocGeo 圖示，副檔名以灰色顯示。要讓每種格式擁有自己的圖示，請打開「終端機」（按 ⌘ 空白鍵，然後輸入「終端機」），貼上下面這行指令並按 Return 鍵： 

curl -fsSL https://doctools.org/apps/docgeo/macos-icons.sh | sh

瀏覽器更新後，這些圖示仍會保留。此指令不需要密碼：它會建立一個小 App「DocGeo Types」，它只宣告圖示，從不打開。由其他軟體（DGPad…）開啟的格式保留該軟體的圖示。

如果圖示沒有改變，表示 macOS 在記憶體中保留了舊圖示。貼上下面這行指令並輸入密碼（輸入時不會顯示）：電腦將重新啟動。 

sudo rm -rf /Library/Caches/com.apple.iconservices.store && sudo reboot

要恢復原來的圖示，請先貼上下面這行指令，再貼上前一行指令：

curl -fsSL https://doctools.org/apps/docgeo/macos-icons.sh | sh -s uninstall

更新

DocGeo 會自動更新。新版本在 DocGeo 開啟時下載，並在關閉其所有視窗後的下一次啟動時生效。離線時，DocGeo 繼續使用現有版本。

解除安裝

在 DocGeo 視窗中，開啟瀏覽器的 ⋮ 選單，然後選擇解除安裝 DocGeo。在 Windows 中，也可以透過設定 › 應用程式解除安裝 DocGeo。你的圖形不受影響。

在 Firefox 和 Safari 中

Firefox 無法安裝 DocGeo：只能在分頁中使用。Mac 上的 Safari 可以把它加入 Dock（檔案 › 加入 Dock），在獨立視窗中開啟，但無法按兩下開啟圖形。
