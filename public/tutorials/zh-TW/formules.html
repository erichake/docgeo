讀取另一個分頁

在活頁簿中，公式可以像試算表一樣讀取另一個分頁中物件的值：用單引號括起的分頁名稱、一個驚嘆號、物件名稱。 

m = '圖形 1'!c
area = 資料!p * 2
  • 如果分頁名稱不含空格和符號，可以省略引號（資料!p）；名稱中的撇號寫作 \'（'Tom\'s'!c）。
  • 所得的值就是該分頁的公式讀取到的值：點的座標、線段的長度……函數不能讀取。
  • 唯讀：一個分頁中的任何操作都不會改變另一個分頁。回到讀取它的分頁時，值會重新讀取。唯一的例外：程式的全域變數，為整個活頁簿共有。
  • 分頁不能讀取自身，也不能讀取一個讀取它的分頁（「循環參照」）。未知的分頁或物件在輸入時會被拒絕。
  • 重新命名分頁或目前分頁中的物件時，其他分頁的公式會隨之更新。刪除分頁後，讀取它的公式變為未定義。

程式

敘述之間用 ; 或換行分隔；最後一條給出值。

變數 var s = 0（let、const）；s += 2、-=、*=、/=、L[2] = 5
條件 if (a > 0) { … } else { … }
迴圈 for (var k = 0; k < 10; k++) { … }、while (…) { … }、break、continue
函數 function square(u) { return u*u }
列表 L.push(P)、L.pop()、L.concat(M)、L.join(", ")
全域變數 GLOBAL_SET("n", 5)、GLOBAL_INC("n", 1)、GLOBAL_GET("n")
暫停 WAIT(500)：500 毫秒，用於按鈕的程式

程式中的變數會遮蔽同名的物件。無窮迴圈會被中斷。全域變數由圖形的所有程式共用，包括其按鈕。
