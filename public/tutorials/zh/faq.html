常见问题

作图

单击创建了点，而不是打开工具环

单击没有落在对象上。按 Ctrl Z，再瞄准线条。在交叉处附近，单击会创建交点。

工具一直处于激活状态

不先选择对象时，工具面板中的工具是持续的：完成、Esc或✕可退出。先选择对象再选工具时，工具只作图一次。

单击没有作出任何东西

某个模式处于激活状态：橡皮擦（蓝色）、逐步构造、磁铁，或未选工具时的属性面板。按Esc退出。

点击空白处不创建点

工具面板已打开：未选工具时，图形只能被操作。请选择工具面板中的第一个工具点，或关闭工具面板。

(2,5, 1) 得到了一个空间中的点

小数分隔符是点：(2.5, 1)。

L = [1, 2, 3] 被拒绝

大写名称会创建一个点，这里是空间中的点。请写list = [1, 2, 3]。

pi 是未知对象

请写 PI 或 π。

不能把对象命名为 x 或 y

在行首，它们表示方程的开始（y = 2x + 1）。

变换多边形

选择变换，选取确定它的对象，再选多边形：它的像是多边形。要变换多个，按住 Shift 选择中心或对称轴（变换对象）。

修改单击创建的圆的半径

拖动圆，或修改其行（圆(O, r)，r 为数、滑动条或公式）。

删除一个点时其他对象也被删除了

依赖对象会随之删除。先撤销，然后隐藏该点而不是删除它。

3D 与视图

“3D 视图”无法返回平面

有对象离开了平面 z = 0；提示会指出该对象。

用鼠标旋转

右键；左键平移视图。

在平板上缩放

双指张开可放大图形，合拢可缩小图形。双指一起拖动可平移视图。

踪迹消失了

每次平移或缩放视图时踪迹都会被清除。

文件

用 ?url= 打开的图形无法加载

文件必须共享给知道链接的任何人，不设密码，并且 ?url= 必须放在网址的最后（见通过链接分享图形）。不支持学校或工作账户的 OneDrive 链接，也不支持拒绝自动下载的网站。

电子表格的位置显示“⚠ DocCells”

电子表格无法加载：在自行托管 DocGeo 副本的网站上，doccells文件夹必须发布在其旁边（电子表格）。图形的其余部分正常工作。

撤销不会撤销电子表格中的输入

单元格有自己的撤销：在单元格中按Ctrl Z，或使用电子表格的菜单（撤销与保存）。

=GEO("A")给出#N/A

GEO只读取数字、文本和布尔值：对于点，先创建一个表达式，例如xA = x(A)（GEO）。

导入不完整

列出的元素不受支持（导入 DGPad 和 GeoGebra 图形）；图形的其余部分可以正常使用和保存。
