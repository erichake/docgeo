公式与程序

表达式的语言与 DGPad 相同。DocGeo 自行解释它：它从不作为 JavaScript 执行。

值

写法 值
3、-2.5、.5、2e3 数（小数点）
PI、π π（不识别 pi）
1 + 2i 复数
"文本" 文本；+ 用于连接
[1, 2, 3] 列表；[x, y]、[x, y, z]：点或向量
A 点：坐标；线段：长度；圆：半径；多边形：面积；角：度数
x、y、z、t 函数的变量

在平面中，点是一个复数：(A + B)/2 是中点，2*B - A是 A 关于 B 的对称点。

运算符

+ - * / ^ % 运算、乘方、余数
2x、2π、3(x + 1) 隐式乘法
== != < <= > >= 比较，值为 1 或 0；== 容许舍入误差
&& || ! 与、或、非
test ? a : b 条件
L[0]、A[1] 元素、坐标（从 0 开始）
L.length 列表的长度

函数

函数 值
d(A, B)、distance(A, B) 距离（3D 中为空间距离）
x(A)、y(A) 坐标
Angle360(A, O, B)、Angle180(A, O, B) 从 [OA) 到 [OB) 的有向角；几何角 AOB
sqrt、abs、exp、log 平方根、绝对值、指数函数、自然对数
sin、cos、tan、asin、acos、atan、atan2(y, x) 按图形的角度设置使用度或弧度（默认为度）
floor、ceil、round 取整
min(…)、max(…)、gcd(a, b)、isNaN(a) 最小值、最大值、最大公约数、检测未定义值
arg、mod、conj 辐角、模、共轭
dot(u, v)、cross(u, v)、unitVector(u)、perp(u) 数量积和向量积、单位向量、垂直单位向量
pixel()、windoww()、windowh()、windowcx()、windowcy() 每单位像素数；以单位表示的窗口大小和中心
theta()、phi() 3D 相机的角度
f(2) 调用一个关于 x 的函数表达式

程序

语句之间用 ; 或换行分隔；最后一条给出值。

变量 var s = 0（let、const）；s += 2、-=、*=、/=、L[2] = 5
条件 if (a > 0) { … } else { … }
循环 for (var k = 0; k < 10; k++) { … }、while (…) { … }
函数 function square(u) { return u*u }
列表 L.push(P)、L.pop()、L.concat(M)、L.join(", ")

程序中的变量会遮蔽同名的对象。无限循环会被中断。

对象的方法

S.setHidden(1)、S.setShowName(1) 隐藏、显示名称（0：相反）
S.setRGBColor(r, g, b)、S.setOpacity(o)、S.setSize(t) 颜色（0 到 255）、不透明度（0 到 1）、大小或粗细
a.setPrecision(n)、a.setIncrement(p) 小数位数、滑动条的增量
P.getX()、P.getY()、P.coords3D()、P.coords2D() 坐标；屏幕坐标
S.getName()、c.center() 名称、圆的圆心 
if (a < 0) {
    p.setRGBColor(220, 38, 38)
} else {
    p.setRGBColor(37, 99, 235)
};
"a = " + a

程序是它所设置样式的对象的父对象：它随图形一起重新计算，会造成循环依赖的重新定义会被拒绝。
