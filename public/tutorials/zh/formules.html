读取另一个标签页

在工作簿中，公式可以像电子表格一样读取另一个标签页中对象的值：用单引号括起的标签页名称、一个感叹号、对象名称。 

m = '图形 1'!c
area = 数据!p * 2
  • 如果标签页名称不含空格和符号，可以省略引号（数据!p）；名称中的撇号写作 \'（'Tom\'s'!c）。
  • 所得的值就是该标签页的公式读取到的值：点的坐标、线段的长度……函数不能读取。
  • 只读：一个标签页中的任何操作都不会改变另一个标签页。回到读取它的标签页时，值会重新读取。唯一的例外：程序的全局变量，为整个工作簿共有。
  • 标签页不能读取自身，也不能读取一个读取它的标签页（“循环引用”）。未知的标签页或对象在输入时会被拒绝。
  • 重命名标签页或当前标签页中的对象时，其他标签页的公式会随之更新。删除标签页后，读取它的公式变为未定义。

程序

语句之间用 ; 或换行分隔；最后一条给出值。

变量 var s = 0（let、const）；s += 2、-=、*=、/=、L[2] = 5
条件 if (a > 0) { … } else { … }
循环 for (var k = 0; k < 10; k++) { … }、while (…) { … }、break、continue
函数 function square(u) { return u*u }
列表 L.push(P)、L.pop()、L.concat(M)、L.join(", ")
全局变量 GLOBAL_SET("n", 5)、GLOBAL_INC("n", 1)、GLOBAL_GET("n")
暂停 WAIT(500)：500 毫秒，用于按钮的程序

程序中的变量会遮蔽同名的对象。无限循环会被中断。全局变量由图形的所有程序共享，包括其按钮。

对象的方法

S.setHidden(1)、S.setShowName(1) 隐藏、显示名称（0：相反）
S.setRGBColor(r, g, b)、S.setOpacity(o)、S.setSize(t) 颜色（0 到 255）、不透明度（0 到 1）、大小或粗细
a.setPrecision(n)、a.setIncrement(p) 小数位数、滑动条的增量
P.getX()、P.getY()、P.coords3D()、P.coords2D() 坐标；屏幕坐标
S.getName()、c.center() 名称、圆的圆心 
if (a < 0) {
    p.setRGBColor(220, 38, 38)
} else {
    p.setRGBColor(37, 99, 235)

程序是它所设置样式的对象的父对象：它随图形一起重新计算，会造成循环依赖的重新定义会被拒绝。
