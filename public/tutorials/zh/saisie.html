用键盘作图

每个对象一行：名称 = 命令(参数)，在“作图”面板的输入行中输入，按 Enter 确认。 

A = (-5, -2)
B = (4, -3)
C = (-1, 4)
p = 多边形(A, B, C)
c = 外接圆(A, B, C)
M = 中点(A, B)

语法

元素 规则
自由点 A = (2, 3)；3D 中为A = (2, 3, 1)
极坐标 P = (3; 60°)：半径和角，用分号隔开
自由向量 u = (2, 1)：名称用小写字母；从原点画出，拖动其终点即可移动
数 小数分隔符为点（2.5）；(1,5, 2)是一个有三个坐标的点
命令 不区分大小写和重音符号，也接受英文名称；该行会改写为通常形式
数作为参数 数、表达式或滑动条的名称，或公式：圆(A, 2*r)
点作为参数 已命名的点、坐标或公式：直线((0, 7), (1, 7))、线段(A, (3; 60°))、直线(A, 点(A + [1, 0]))、直线(L(1), L(2))、直线(L[0], L[1])；这些点属于对象本身，没有单独的一行，并且是固定的：对象不能拖动
省略名称 中点(A, B)：自动命名，点用大写字母，向量用 u、v、w，角用希腊字母，其他用小写字母（不用 e、i、k、l、o、t、x、y、z）
未知名称 以小写字母开头时，成为一个滑动条：A = (a, 4)、d = y = m x + p
已有名称 该行重新定义此对象
特殊名称 可使用撇号（A'）；其他字符放在反引号之间（`aux 2`）
应避免的名称 x、y（方程）、i（虚数单位）
其他行 既不是点也不是命令：一个表达式（a = 3、E = d(A, B)）

各命令的形式和参数：命令。

自动补全与选取

  • 在行首，列表提示命令；在括号内，只提示当前参数可接受的对象，并在图形中高亮显示。↑ ↓ 选择，Tab 或Enter 插入，Esc 关闭。
  • 点击一个对象会写入其名称，后面根据还需选取的内容加上, 或 )：M = 中点(，点击 A，再点击 B，得到 M = 中点(A, B)。
  • 在输入行中，点击没有点的地方会创建一个点（自由点、对象上的点或交点）；预览跟随指针。再次点击多边形的第一个顶点即可完成多边形。
  • 在公式中也一样：E = d(，点击 H，再点击 M。

修改一行

面板中的每一行都是一个输入框：Enter 确认，Esc还原。

  • 新坐标：移动自由点。
  • 新定义：对象被重新定义，保留其样式，其依赖对象随之改变（M = 中点(A, B) → M = (5, 5) → M = 中点(B, C)）。必要时会重新排列作图顺序；循环依赖会被拒绝。
  • 新名称：对象在所有行和公式中都会被重命名。
  • A = 删除 A 及其依赖对象。
  • 长命令：在属性的定义部分中打开它，分多行显示，补全相同；点击图形中的对象会插入其名称，⌘-Enter应用。

方程

用 = 分隔的关于 x、y（和 z）的两边；对象类型由系数决定，系数可以依赖于滑动条。

行 对象
d = y = a*x + b、x = 3 直线
c = x^2 + y^2 = 4 圆
e = x^2/9 + y^2/4 = 1 圆锥曲线
p = x + y + z = 3 平面（3D）

次数高于 2 或非多项式：拒绝。在行首，z是名称：z = 3 是表达式，平面应写作p = z = 3。

不等式

关于 x 和 y 的比较给出它成立的区域，并填充颜色：<, <= 或 ≤, >, >= 或 ≥，可用 && 或 ∧ (且), || 或 ∨ (或) 组合。

行 对象
x < 2 半平面
a(x, y) = x^2 + y^2 ≤ 4 圆盘
b(x, y) = y ≥ x^2 ∧ y ≤ 4 抛物线与直线之间
c(x, y) = a(x, y) ∧ b(x, y) a 与 b 的公共部分

该行重读为 a(x, y) = …，使用 ≤、≥、∧ 和 ∨；公式可以像调用 x 和 y 的函数一样调用该区域，除非它与某个公式函数同名（如 d）。仅比较数的式子（F = r < 3）仍是表达式，值为 1 或 0。GeoGebra 图形中的不等式也以同样方式打开。

曲面

在 3D 中，不含比较的 x 和 y 的函数给出曲面 z = g(x, y)，画在视图的盒子内：g(x, y) = x^2 - y^2。公式可以像函数一样调用它：g(1, 2)。交点(d, g, n) 给出它在直线上的点。在平面图形中，同一行仍是 x 和 y 的表达式。GeoGebra 图形中的曲面（二元函数、二次曲面 z = …）也同样打开。

交点与对象上的点

  • 两条直线用 交点(d1, d2)；其他情况用交点(c, d, n)，n 为 1 到 4；在 3D 中，直线与球、圆柱或圆锥用 交点(d, s, n)，n = 1 或 2。
  • 另一交点(c, d, P)：离 P 最远的公共点。
  • 点(c, t)，或多边形、圆锥曲线上的点(p, a, b)：在对象上的位置，由手势写出。a、b 是对象的一个坐标系中的坐标（见命令）。

错误

有错误的行不会被应用：它保持红框，提示给出原因，图形的其余部分不受影响。

信息 原因
无法理解 括号、逗号或字符
未知命令、未知对象 名称拼写错误或不存在
… 的参数不正确 没有匹配的形式；“使用这些参数”会列出各种形式
名称 … 已被占用 重命名
对象不能依赖于自身 循环依赖
平面图形的对象都在平面 z = 0 内… 空间对象：切换到 3D 视图
此对象暂时无法写成文本 没有命令的导入对象：只读行 名称 = …
