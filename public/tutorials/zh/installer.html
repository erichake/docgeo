安装 DocGeo

在 Chrome 和 Edge 中，无论是 macOS、Windows 还是 Linux，DocGeo 编辑器都可以像应用程序一样安装到电脑上。既不需要管理员权限，也不需要下载任何软件。

安装

  1. 在 Chrome 或 Edge 中打开编辑器。
  2. 选择文件 › 在此电脑上安装 DocGeo…
  3. 点击安装确认：DocGeo 会立即在自己的窗口中打开。

只有当浏览器提供安装时才会出现此菜单项：已安装的 DocGeo 中不会出现，Firefox 和 Safari 中也不会出现。浏览器也会通过地址栏右侧的图标提供安装。

安装后的好处

  • DocGeo 拥有自己的窗口，没有地址栏和标签页，可以像普通软件一样从程序坞、开始菜单或应用程序菜单启动。
  • 无需联网即可使用（离线使用）。
  • 双击 .dgo、.dgp 或 .ggb 图形，即可在 DocGeo 中打开（双击打开图形）。

离线使用

首次联网打开之后，DocGeo 无需联网即可打开和使用：作图，以及在电脑上打开和保存文件。只有通过链接打开的图形（通过链接分享图形）和本手册需要联网。

双击打开图形

安装后的 DocGeo 可以打开 .dgo、.dgp 和 .ggb 文件：双击其中任一文件，即在 DocGeo 窗口中显示。以这种方式打开的 .dgo 图形会保存回原文件。

如果其他软件已经在打开这些文件（DGPad、GeoGebra…），请一次性改为 DocGeo：在 Mac 的访达中，显示简介 › 打开方式，选择 DocGeo，再点全部更改；在 Windows 中，右键点击文件，选择打开方式。

Mac 上的图形图标

在 Mac 上，图形的图标是一页纸上的 DocGeo 图标，扩展名以灰色显示。要让每种格式拥有自己的图标，请打开“终端”（按 ⌘ 空格，然后输入“终端”），粘贴下面这行命令并按回车键。

注意：该命令只要求输入密码（输入时不显示），随后立即重新启动电脑，因为 macOS 必须清空图标缓存。粘贴命令之前，请先保存工作并退出各个应用。 

curl -fsSL https://doctools.org/apps/docgeo/macos-icons.sh | sh

浏览器更新后，这些图标仍会保留。该命令会创建一个小应用 DocGeo Types，它只声明图标，从不打开。由其他软件（DGPad…）打开的格式保留该软件的图标。

要恢复原来的图标，请粘贴下面这行命令，它同样会重新启动电脑：

curl -fsSL https://doctools.org/apps/docgeo/macos-icons.sh | sh -s uninstall

Windows 上的图形图标

在 Windows 上，由 DocGeo 打开的图形显示为空白图标。要让每种格式拥有自己的图标，请打开 PowerShell（在“开始”菜单中输入 PowerShell），粘贴下面这行命令并按回车键。该命令不要求输入任何内容，也不会重新启动电脑。 

irm https://doctools.org/apps/docgeo/windows-icons.ps1 | iex

请在安装 DocGeo 之后运行它；如果浏览器更新后图标消失，请再次运行。如果某种格式还不是用 DocGeo 打开（DGPad…），命令会提示：请为该格式选择 DocGeo（双击打开图形）。

要恢复原来的图标，请粘贴下面这行命令：

& ([scriptblock]::Create((irm https://doctools.org/apps/docgeo/windows-icons.ps1))) uninstall

更新

DocGeo 会自动更新。新版本在 DocGeo 打开时下载，并在关闭其所有窗口后的下一次启动时生效。离线时，DocGeo 继续使用现有版本。

卸载

在 DocGeo 窗口中，打开浏览器的 ⋮ 菜单，然后选择卸载 DocGeo。在 Windows 中，也可以通过设置 › 应用卸载 DocGeo。你的图形不受影响。

在 Firefox 和 Safari 中

Firefox 不能安装 DocGeo：只能在标签页中使用。Mac 上的 Safari 可以把它添加到程序坞（文件 › 添加到程序坞），在独立窗口中打开，但不能通过双击打开图形。
