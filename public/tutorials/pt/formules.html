Fórmulas e programas

A linguagem das expressões é a do DGPad. O DocGeo a interpreta ele mesmo: ela nunca é executada como JavaScript.

Valores

Escrita Valor
3, -2.5, .5, 2e3 números (ponto decimal)
PI, π π (pi não é reconhecido)
1 + 2i número complexo
30° ângulo em graus, convertido na unidade de ângulo da figura
"texto" texto; + concatena

A ponto: coordenadas; segmento: comprimento; círculo: raio; polígono: área; ângulo: medida

No plano, um ponto é um número complexo: (A + B)/2 é o ponto médio, 2*B - A o simétrico de A em relação a B.

Ler outra página

Numa pasta de trabalho, uma fórmula lê o valor de um objeto de outra página, como numa planilha: o nome da página entre aspas simples, um ponto de exclamação, o nome do objeto. 

m = 'Página 1'!c
area = Dados!p * 2
  • As aspas são desnecessárias se o nome da página não tiver espaços nem sinais (Dados!p); um apóstrofo do nome escreve-se \' ('D\'Ávila'!c).
  • O valor é o que uma fórmula dessa página leria: coordenadas de um ponto, comprimento de um segmento… Uma função não pode ser lida.
  • Somente leitura: nada numa página modifica outra página. O valor é relido ao voltar à página que o lê. Única exceção: as globais dos programas, comuns a toda a pasta de trabalho.
  • Uma página não pode ler a si mesma, nem ler uma página que a lê («Referência circular»). Uma página ou um objeto desconhecido é recusado na digitação.
  • Renomear uma página, ou um objeto da página mostrada, atualiza as fórmulas das outras páginas. Depois da eliminação de uma página, as fórmulas que a liam ficam indefinidas.

Programas

Instruções separadas por ; ou quebras de linha; a última dá o valor.

variáveis var s = 0 (let, const); s += 2, -=, *=, /=, L[2] = 5
condições if (a > 0) { … } else { … }
laços for (var k = 0; k < 10; k++) { … }, while (…) { … }, break, continue
funções function quadrado(u) { return u*u }
listas L.push(P), L.pop(), L.concat(M), L.join(", ")
globais GLOBAL_SET("n", 5), GLOBAL_INC("n", 1), GLOBAL_GET("n")
pausa WAIT(500): 500 ms, no programa de um botão

As variáveis de um programa escondem os objetos de mesmo nome. Um laço infinito é interrompido. As globais são partilhadas por todos os programas da figura, incluindo os seus botões.

Métodos dos objetos

S.setHidden(1), S.setShowName(1) ocultar, exibir o nome (0: o contrário)
S.setRGBColor(r, g, b), S.setOpacity(o), S.setSize(t) cor (0 a 255), opacidade (0 a 1), tamanho ou espessura
a.setPrecision(n), a.setIncrement(p) casas decimais, incremento de um controle deslizante
P.getX(), P.getY(), P.coords3D(), P.coords2D() coordenadas; coordenadas na tela
S.getName(), c.center() nome, centro de um círculo 
if (a < 0) {
    p.setRGBColor(220, 38, 38)
} else {
    p.setRGBColor(37, 99, 235)
};
"a = " + a

Um programa é pai dos objetos que formata: ele é recalculado com a figura, e uma redefinição que criaria um ciclo é recusada.
