Formule e programmi

Il linguaggio delle espressioni è quello di DGPad. DocGeo lo interpreta da sé: non viene mai eseguito come JavaScript.

Leggere un’altra scheda

In una cartella di lavoro, una formula legge il valore di un oggetto di un’altra scheda, come in un foglio di calcolo: il nome della scheda tra apici, un punto esclamativo, il nome dell’oggetto. 

m = 'Figura 1'!c
area = Dati!p * 2
  • Gli apici non servono se il nome della scheda non ha spazi né segni (Dati!p); un apostrofo del nome si scrive \' ('L\'area'!c).
  • Il valore è quello che leggerebbe una formula di quella scheda: coordinate di un punto, lunghezza di un segmento… Una funzione non si può leggere.
  • Sola lettura: niente in una scheda modifica un’altra scheda. Il valore viene riletto quando si torna alla scheda che lo legge. Unica eccezione: le globali dei programmi, comuni a tutta la cartella di lavoro.
  • Una scheda non può leggere se stessa, né una scheda che la legge («Riferimento circolare»). Una scheda o un oggetto sconosciuto viene rifiutato all’inserimento.
  • Rinominare una scheda, o un oggetto della scheda mostrata, aggiorna le formule delle altre schede. Dopo l’eliminazione di una scheda, le formule che la leggevano sono indefinite.

Leggere una cella del foglio di calcolo

In una scheda con una vista foglio di calcolo, una formula legge le sue celle con un punto esclamativo seguito dal loro indirizzo: una cella, un intervallo (lista) o la cella di una scheda foglio di calcolo. 

r = !B3
L = !B2:B21
k = Foglio1!A1

Una cella vuota o in errore dà un valore indefinito. Nel senso inverso, una cella legge un oggetto della figura con =GEO("nome") (GEO).

Programmi

Istruzioni separate da ; o da a capo; l’ultima dà il valore.

variabili var s = 0 (let, const); s += 2, -=, *=, /=, L[2] = 5
condizioni if (a > 0) { … } else { … }
cicli for (var k = 0; k < 10; k++) { … }, while (…) { … }, break, continue
funzioni function quadrato(u) { return u*u }
liste L.push(P), L.pop(), L.concat(M), L.join(", ")
globali GLOBAL_SET("n", 5), GLOBAL_INC("n", 1), GLOBAL_GET("n")
pausa WAIT(500): 500 ms, nel programma di un pulsante

Le variabili di un programma nascondono gli oggetti con lo stesso nome. Un ciclo infinito viene interrotto. Le globali sono condivise da tutti i programmi della figura, pulsanti compresi.

Metodi degli oggetti

S.setHidden(1), S.setShowName(1) nascondere, mostrare il nome (0: il contrario)
S.setRGBColor(r, g, b), S.setOpacity(o), S.setSize(t) colore (da 0 a 255), opacità (da 0 a 1), dimensione o spessore
a.setPrecision(n), a.setIncrement(p) decimali, incremento di uno slider
P.getX(), P.getY(), P.coords3D(), P.coords2D() coordinate; coordinate sullo schermo
S.getName(), c.center() nome, centro di una circonferenza 
if (a < 0) {
    p.setRGBColor(220, 38, 38)
} else {
    p.setRGBColor(37, 99, 235)
};
"a = " + a

Un programma è genitore degli oggetti che formatta: viene ricalcolato con la figura, e una ridefinizione che creerebbe un ciclo viene rifiutata.
